# Lab Activity 2: Student Management System



A Python application for managing student records using standard data structures (Dictionaries, Lists, Tuples, Strings) with full CRUD operations.



Requirements

\- Python 3.x



How to Run



1\. Open PowerShell in the project directory.

2\. Enable script execution for the session (if needed):

&#x20;  

&#x09;( Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process ) - paste this



3\. Activate the virtual environment:



&#x09;( .\\venv\\Scripts\\Activate.ps1 )



4\. Run the app:



&#x09;( python student\_management.py )
